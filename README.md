# Minerthal: modelo de redesign

Protótipo estático da nova home da Minerthal (https://www.minerthal.com.br/), publicado via GitHub Pages para aprovação do cliente.

- index.html: página única, CSS e JS inline, sem dependências externas.
- ssets/img: imagens em WebP com srcset (originais do site oficial).
- ssets/fonts: Barlow e Barlow Condensed (latin, woff2) servidas localmente.
- ssets/catalogo.json: 43 produtos com as tags do catálogo oficial.
- llms.txt e obots.txt: descrição para buscadores de IA e regras de rastreamento.

A página usa rel=canonical para o domínio oficial, para não competir com ele no Google.
